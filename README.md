# 今日の一句 — GAS版 セットアップ・デプロイ手順書

## ファイル構成

```
today-haiku-gas/
├── Code.gs       ← GAS バックエンド（スプレッドシート操作・API）
└── index.html    ← フロントエンド（HTML + CSS + JS 一体型）
```

---

## 1. Google スプレッドシートを作成する

1. [Google スプレッドシート](https://sheets.google.com) を開き、**新しいスプレッドシート**を作成
2. スプレッドシートの名前は任意（例：「今日の一句DB」）
3. **シート名は変更しない**（後でスクリプトが自動作成します）

---

## 2. Google Apps Script プロジェクトを作成する

1. スプレッドシートのメニューから  
   `拡張機能` → `Apps Script` をクリック
2. 左のファイル一覧に `コード.gs` が表示される
3. `コード.gs` の中身を**すべて削除**し、`Code.gs` の内容を**貼り付け**て保存（Ctrl+S）
4. 左上の `+` ボタン → `HTML` を選び、ファイル名を `index`（`.html` は自動付与）と入力
5. `index.html` の中身を**すべて削除**し、`index.html` の内容を**貼り付け**て保存

---

## 3. Webアプリとしてデプロイする

1. 右上の **「デプロイ」→「新しいデプロイ」** をクリック
2. 歯車アイコン → **「ウェブアプリ」** を選択
3. 以下のように設定する：

   | 項目 | 設定値 |
   |------|--------|
   | 説明 | 今日の一句 v1.0 |
   | 次のユーザーとして実行 | **自分（自分のGoogleアカウント）** |
   | アクセスできるユーザー | **全員**（匿名ユーザーを含む） |

   > ⚠️ 「全員」にしないと未ログインユーザーが使えません

4. **「デプロイ」** をクリック
5. 「承認が必要です」が出たら → **「アクセスを承認」** → Googleアカウントでログイン → 「詳細」→「安全でないページへ移動」→「許可」
6. 表示された **ウェブアプリURL** をコピーして保存

   ```
   例: https://script.google.com/macros/s/AKfycby.../exec
   ```

7. このURLがアプリの公開URLです。ブラウザで開いて動作確認してください

---

## 4. 動作確認

- アプリURLにアクセスし、句が投稿できるか確認
- スプレッドシートに `posts` シートが自動作成され、データが記録されているか確認
- `session_id` 列が非表示になっていることを確認

---

## 5. 更新・再デプロイ方法

コードを修正した場合：

1. `デプロイ` → `デプロイを管理`
2. 鉛筆アイコン（編集）→ バージョンを **「新しいバージョン」** に変更
3. `デプロイ` をクリック

> ⚠️ 「既存のバージョン」のままだとコードが反映されません

## セキュリティ設計の解説

### ✅ 実装済みの対策

| 脅威 | 対策 |
|------|------|
| **XSS（クロスサイトスクリプティング）** | サーバー側で全入力をサニタイズ（制御文字除去）。フロントでは `textContent` / `esc()` 関数で HTML エスケープ |
| **不正な編集・削除** | `sessionId`（UUID v4）をサーバー側で検証。スプレッドシートの `session_id` 列と照合し、一致しない場合はエラー |
| **sessionId の偽造** | UUID v4 の正規表現でフォーマット検証。総当たりは天文学的に困難（2^122 通り） |
| **不正な値の注入** | `type`・`generation` は許可リストと照合。`phrases` の配列長・文字数も検証 |
| **スプレッドシートへの直接アクセス** | スプレッドシートは非公開。GAS経由でのみアクセス可能 |
| **`session_id` 列の漏洩** | `rowToPublicPost()` 関数で `session_id` を除外してクライアントに返却。シート上も列を非表示設定 |
| **クリックジャッキング** | `setXFrameOptionsMode(DENY)` で iframe 埋め込みを禁止 |
| **二重座布団投票** | クライアント localStorage + サーバー側カウントで管理 |

### ⚠️ 制限事項・注意点

- **sessionId はブラウザの localStorage に保存**されます。同じブラウザ・同じデバイスから投稿した記事のみ編集・削除できます。別デバイスからは不可です（意図的な仕様）
- **完全な認証ではありません**。sessionId を手動で書き換えられると別人の投稿を操作できる可能性があります。本番の厳密な認証が必要な場合は Firebase Authentication 等を追加してください
- **レートリミット**：GAS の無料枠には1日あたりの実行回数制限（約20万回/日）があります。大規模利用の場合は Google Workspace のプランをご検討ください
- **同時書き込み競合**：GAS の `appendRow` / `setValue` には排他制御がないため、大量同時投稿時にまれに競合が起きる場合があります。本番利用では `LockService` の追加をご検討ください

### 🔒 さらに強化する場合（オプション）

```javascript
// Code.gs の actionCreatePost 冒頭に追加すると同時書き込み競合を防止
const lock = LockService.getScriptLock();
lock.waitLock(5000);
try {
  // ... 処理 ...
} finally {
  lock.releaseLock();
}
```

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| 「読み込みに失敗しました」 | デプロイ時の「アクセスできるユーザー」が「全員」になっているか確認 |
| 投稿しても反映されない | 再デプロイ（新しいバージョン）を行ったか確認 |
| 編集・削除ボタンが出ない | 同じブラウザ・デバイスから投稿した記事のみ表示されます |
| スプレッドシートにデータがない | `posts` シートが自動作成されているか確認。Apps Script の「実行ログ」でエラーを確認 |
